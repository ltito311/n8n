# Eleven's Restaurant Website

A luxury, mobile-responsive website for Eleven's dining and lounge experience in Savanna-la-Mar, Jamaica.

## 🌟 Features

### Design & User Experience
- **Premium Design**: Luxury aesthetic with gold and dark color scheme
- **Mobile-First**: Fully responsive design optimized for all devices
- **Modern Animations**: Smooth scroll animations and hover effects
- **Interactive Elements**: Sticky navigation, lightbox gallery, smooth scrolling

### Pages & Functionality

#### 🏠 Homepage (`index.html`)
- Hero section with call-to-action
- About preview with restaurant stats
- Menu category preview
- Experience features showcase
- Location section with Google Maps integration
- Complete footer with social links

#### 🍽️ Menu Page (`menu.html`)
- Dedicated menu hero section
- Sticky category navigation
- Organized menu sections:
  - Appetizers
  - Main Courses
  - Beverages
  - Desserts
- Individual menu items with prices and descriptions
- Call-to-action for reservations

#### 🖼️ Gallery Page (`gallery.html`)
- Instagram feed integration (using provided embed code)
- Organized gallery categories:
  - Food
  - Drinks
  - Ambience
  - Events
- Interactive lightbox functionality
- Image sharing capabilities
- Keyboard navigation support

## 🔧 Installation & Setup

1. **Clone or download** the project files
2. **Open** `index.html` in a web browser
3. **No build process required** - pure HTML, CSS, and JavaScript
